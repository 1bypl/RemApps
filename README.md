# RemApps-
RemApps to małe narzędzie i działa jak Discover czy inne menedżery, które często pokazują tylko to, co znajduje się w ich bazie. Programy doinstalowane ręcznie, z Internetu (AppImage), z Flatpak/Snap albo starsze resztki konfiguracji bywają niewidoczne. RemApps łączy wszystkie te źródła w jednym oknie i pokazuje dokładnie, co zostanie usunięte.
